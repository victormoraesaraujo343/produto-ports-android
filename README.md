# produto-ports-android

Launcher Android de ports recompilados e decompilados, com a cara do Hydra. Ele instala o APK oficial de cada port, ajuda a colocar o arquivo do jogo e abre o jogo. Não contém nenhum dado de jogo.

- O que é e por quê: [`VISION.md`](VISION.md)
- O que já foi decidido: [`DECISIONS.md`](DECISIONS.md)
- Como vai funcionar por dentro: [`ARCHITECTURE.md`](ARCHITECTURE.md)
- Ordem do trabalho e situação atual: [`ROADMAP.md`](ROADMAP.md) · [`STATUS.md`](STATUS.md)
- Regras pra IA: [`AGENTS.md`](AGENTS.md)

## Lab

```sh
npm install
npm run lab   # http://localhost:5192/laboratorio/index.html
```

Deitado é a vista padrão. Pra ver a versão em pé, aperte **V** no painel. O painel de Refinamento abre e fecha com **R**.
